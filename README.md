# Priya James Portfolio

A static, dependency-free portfolio for Priya James. The site uses the PJ monogram, a warm cream background, olive-green accents, and editorial typography.

## Pages

- `index.html` — homepage, about, selected case studies, experience, credentials, and contact
- `case-studies.html` — interactive case-study index
- `case-policy-compliance.html`
- `case-tprm.html`
- `case-legacy-modernization.html`
- `case-cloud-governance.html`
- `case-security-operations.html`
- `case-grc-portal.html`
- `case-esg-data.html`
- `case-practice-build.html`
- `case-grc-agent.html`
- `case-ai-governance.html`

## Run locally

Open `index.html` in a browser. No build step or package installation is required. Google Fonts are loaded remotely; system-font fallbacks are defined in the CSS.

## Deploy

This is a static site. Publish the contents of this folder to a static host (for example, Vercel, Netlify, or GitHub Pages). For Vercel, import the repository and use the project root as the root directory; no build command is needed and the output directory can be left at the project root.

## Before publishing

- Review every case study and confirm all descriptions, outcomes, metrics, and client/industry references are accurate and approved for public disclosure.
- Confirm that Priya is comfortable publishing the email address currently shown in `index.html` (`priyajames.m@gmail.com`).
- Verify credential names and dates against the current résumé.
- Confirm that the portrait in `assets/priya-profile.png` is approved for public use.

## Notes

The site uses text-based labels rather than fabricated client logos. Case-study narratives should be treated as drafts until approved for public use. No deployment or DNS changes are performed by this project archive.
